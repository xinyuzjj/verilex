How it works

1. CRE cron trigger fires the compliance workflow.
2. HTTP capability fetches the custodian's signed attestation (reserves, licence, legal doc hash, audit).
3. EVM capability reads totalSupply() from the TokenizedAsset contract.
4. The agent evaluates the rule set and builds the reasoning trail; the trail is hashed.
5. The verdict + reserve ratio + report hash are written to ComplianceRegistry — verifiable by anyone, forever.

Why it matters

RWA tokenization is only as trustworthy as its off-chain promises. Today, reserve and legal compliance checks are manual, periodic and opaque. VeriLex turns them into a continuous, automated, on-chain-verifiable process — so a lapsed custodian licence or a reserve shortfall becomes public the moment it is detected, not months later in an audit PDF.

Demo data: the custodian API is simulated for the hackathon; the agent logic, contracts and CRE workflow are real and runnable from the repository. Verdicts are computed by a transparent rule set; an optional LLM only drafts the plain-language summary.
